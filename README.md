An entry for the make.fun bounty. `python3 main.py` writes one original line to
`/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write somewhere else for local
testing. Run `python3 -m unittest -v test_entry.py` to check the entry and the
candidate selection against the brief.
